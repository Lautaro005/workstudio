PreguntasQuestions

Lo que conviene saber.Good to know.

¿Necesito tener instaladas brain, Lumina y OpenCue?Do I need brain, Lumina and OpenCue installed?

No. WorkStudio funciona solo y te muestra cuáles faltan, con un botón para instalar cada una.No. WorkStudio works on its own and shows which ones are missing, with a button to install each.

¿Mis datos salen de la compu?Does my data leave my computer?

No. Solo habla con tus apps en 127.0.0.1, con GitHub y npm para ver versiones nuevas, y con la web solo si usás la búsqueda del chat. Detalles en la política de privacidad.No. It only talks to your apps on 127.0.0.1, to GitHub and npm to check for new versions, and to the web only if you use the chat's search. Details in the privacy policy.

¿Qué toca cuando conecto un cliente MCP?What does connecting an MCP client change?

Agrega el servidor workstudio a la config de ese cliente y guarda una copia .bak-workstudio la primera vez. Desconectar quita solo lo que puso.It adds the workstudio server to that client's config and keeps a .bak-workstudio copy the first time. Disconnecting removes only what it added.

¿Cómo lo actualizo o lo desinstalo?How do I update or uninstall it?

Se actualiza solo desde Actualizaciones, o con workstudio update. Para sacarlo: workstudio uninstall.It updates itself from Updates, or with workstudio update. To remove it: workstudio uninstall.

macOS dice que la app no se puede abrirmacOS says the app can't be opened

Los instaladores todavía no están firmados por Apple. El comando de instalación ya lo resuelve; si bajaste el .dmg a mano, hacé clic derecho → Abrir la primera vez.The installers aren't signed by Apple yet. The install command handles it; if you downloaded the .dmg yourself, right-click → Open the first time.

Un comando. Todo tu estudio.One command. Your whole studio.

En macOS queda en Aplicaciones, en Linux en el menú de apps y en Windows en el menú Inicio. Sin sudo.On macOS it goes to Applications, on Linux to the app menu and on Windows to the Start menu. No sudo.

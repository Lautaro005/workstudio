Qué hace

Un escritorio para tu stack de IA.

01

Todo en una ventana

brain y Lumina se abren dentro de WorkStudio; OpenCue en la suya. Barra lateral con el estado de cada una y un lanzador de apps al estilo Google.

02

Seis terminales

Grilla de hasta seis terminales reales, con perfiles para Claude Code, Codex, Gemini, Cursor, brain, lumina y opencue.

03

MCP compartido

Las herramientas de tus apps en una lista. Llegan solas a las terminales y se conectan a Claude Desktop, Cursor o Codex con un clic.

04

Avisos que importan

Cambios en el vault de brain, reuniones de Lumina, apps que se detienen y versiones nuevas: en el centro de notificaciones y en el sistema.

05

Siempre al día

Revisa GitHub y npm cada pocas horas. Actualiza cada app y cada CLI con un clic, y WorkStudio se actualiza solo con paquetes firmados.

06

⌘K para todo

Abrí una app, iniciá o detené otra, lanzá un agente o buscá actualizaciones sin tocar el mouse.

Preguntas

Lo que conviene saber.

¿Necesito tener instaladas brain, Lumina y OpenCue?

No. WorkStudio funciona solo y te muestra cuáles faltan, con un botón para instalar cada una. Si querés todo de una, usá la opción «con las 3 apps» del comando.

¿Mis datos salen de la compu?

No. WorkStudio solo habla con tus apps en 127.0.0.1, con GitHub para ver versiones nuevas y con npm para las versiones de los CLIs. Sus archivos viven en ~/.workstudio.

¿Qué toca cuando conecto un cliente MCP?

Agrega el servidor workstudio (con las herramientas de todas tus apps) a la config de ese cliente (por ejemplo ~/.claude.json o ~/.codex/config.toml) y guarda una copia .bak-workstudio la primera vez. Si ya tenías brain, Lumina u OpenCue sueltos, los saca para que nada aparezca dos veces. Desconectar quita solo lo que puso WorkStudio.

¿Cómo sumo una app nueva?

Agregándola a ~/.workstudio/apps.json, con el mismo formato que catalog/apps.json. Podés indicar su dirección web, cómo iniciarla, instalarla, actualizarla y su servidor MCP.

¿Cómo lo actualizo o lo desinstalo?

WorkStudio se actualiza solo desde Actualizaciones. También: workstudio update. Para sacarlo: workstudio uninstall (tus ajustes quedan en ~/.workstudio).

macOS dice que la app no se puede abrir

Los instaladores todavía no están firmados con un certificado de Apple. El comando de instalación ya quita la marca de cuarentena; si bajaste el .dmg a mano, hacé clic derecho → Abrir la primera vez.

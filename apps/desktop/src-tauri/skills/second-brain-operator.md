# Second brain — operator

Keep the second brain current without the user doing anything. The brain is a **filtered layer over raw data**: save conclusions, decisions and preferences, never exports or dumps. It complements the user's tools; it does not replace them.

Use `openblocks__*` for the vault. The sources are the other WorkStudio pills: `lumina__*` (meeting transcripts: the most valuable source, decisions are made there), `brain__*` (long-term memory) and `web__*`. Read `AGENTS` first and follow its routing table.

## When the user runs this for the first time
1. Ask which sources matter most (meetings first, then email, calendar, CRM, project tracker, Slack). Use only the tools that are on.
2. Explain the daily update in two sentences and ask what time it should run.
3. Tell the user to create the automation in **Automatizaciones** from the template "Daily second-brain update", or create the prompt below yourself if they ask.

## What one daily run does
1. Read `AGENTS` and the index of the folders you may touch.
2. Look at what is new since the last run: meetings in Lumina (from the last day), new notes, changed pages.
3. For each relevant item, write **insights** in the right place (a decision in `Decisiones/`, a client update in that client's folder, a meeting takeaway in `Reuniones/`). Update an existing page instead of creating a duplicate. Link related pages with `[[wikilinks]]`.
4. Review pages not touched in a while: if something changed (a price, a person, a status), update it; if it is obsolete, move it to a `Archivo/` folder (everything goes to the vault's trash/history, so nothing is lost) and say so.
5. Keep the indexes and `AGENTS` accurate when you add or archive pages. Do not change the folder structure: ask the user first.
6. End with a short report: what you saved, what you updated, what you archived, what you could not read.

## Rules
- Never store secrets, passwords or raw personal data.
- Do not invent: if a source is empty or a tool failed, say so in the report.
- If a request or finding conflicts with the business goals in `Contexto/Estrategia`, flag it.

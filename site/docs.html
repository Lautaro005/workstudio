Qué es

AI WorkStudio es una app de escritorio para macOS, Windows y Linux que junta tus apps de IA locales — brain, Lumina, OpenCue y las que sumes — en un solo lugar. Muestra su estado, sus avisos y sus versiones, las arranca y las detiene, junta sus herramientas en un solo servidor MCP y suma un chat y hasta seis terminales.

Cada app sigue siendo independiente: WorkStudio no las reemplaza, las encuentra y las conecta. Todo corre en tu compu.

What it is

AI WorkStudio is a desktop app for macOS, Windows and Linux that brings your local AI apps — brain, Lumina, OpenCue and any you add — into one place. It shows their status, notifications and versions, starts and stops them, merges their tools into a single MCP server and adds a chat and up to six terminals.

Each app stays independent: WorkStudio doesn't replace them, it finds and connects them. Everything runs on your computer.

Instalar

macOS y Linux

curl -fsSL https://raw.githubusercontent.com/Lautaro005/workstudio/main/install.sh | sh

Opciones (después de sh -s --):

OpciónQué hace
--allInstala también brain, Lumina y OpenCue.
--with brain,luminaInstala solo esas apps además de WorkStudio.
--usermacOS: instala en ~/Applications en vez de /Applications.
--buildCompila desde el código en vez de bajar una versión (necesita git, Node y Rust).
--uninstallQuita WorkStudio; tus datos en ~/.workstudio quedan.

En macOS la app queda en /Applications/AI WorkStudio.app; en Linux en ~/.local/opt/workstudio con una entrada en el menú de apps. En los dos casos se agrega el comando workstudio en ~/.local/bin. No hace falta sudo.

Windows

En PowerShell:

irm https://raw.githubusercontent.com/Lautaro005/workstudio/main/install.ps1 | iex

Con las tres apps:

$env:WORKSTUDIO_WITH = "brain,lumina,opencue"; irm https://raw.githubusercontent.com/Lautaro005/workstudio/main/install.ps1 | iex

Se instala para tu usuario, con acceso en el menú Inicio y el comando workstudio.

Instaladores

También podés bajar el instalador de la última versión: .dmg universal para macOS, .exe o .msi para Windows y .AppImage, .deb o .rpm para Linux.

Primeros pasos

  1. Abrí WorkStudio. En Inicio ves cada app con su estado (corriendo, detenida o no instalada) y su versión.
  2. Instalá lo que falte. Las apps que no tenés muestran un botón Instalar, que corre su instalador en una terminal para que veas cada paso.
  3. Abrí una app. Abrir la inicia si hace falta. brain y Lumina se pueden usar dentro de WorkStudio; OpenCue abre su propia ventana.
  4. Conectá tus agentes. En MCP → Clientes, conectá Claude Code, Claude Desktop, Codex, Cursor, Gemini o Windsurf con un clic.
  5. Probá el chat o una terminal. Los dos ya traen las herramientas de tus apps.

Atajo útil: ⌘K (o Ctrl K) abre una paleta para abrir apps, iniciarlas o detenerlas, abrir terminales y buscar actualizaciones.

First steps

  1. Open WorkStudio. Home shows each app with its status (running, stopped or not installed) and version.
  2. Install what's missing. Apps you don't have show an Install button, which runs their installer in a terminal so you see every step.
  3. Open an app. Open starts it if needed. brain and Lumina can be used inside WorkStudio; OpenCue opens its own window.
  4. Connect your agents. In MCP → Clients, connect Claude Code, Claude Desktop, Codex, Cursor, Gemini or Windsurf in one click.
  5. Try the chat or a terminal. Both already come with your apps' tools.

Handy shortcut: ⌘K (or Ctrl K) opens a palette to open, start or stop apps, open terminals and check for updates.

Sumar apps

Cualquier app local con interfaz web, un comando o un servidor MCP se suma agregándola a la lista apps de ~/.workstudio/apps.json. Si usa el mismo id que una app del catálogo, la tuya gana.

{
  "apps": [
    {
      "id": "mi-app",
      "name": "Mi App",
      "tagline": "Qué hace",
      "kind": "web",
      "url": "http://127.0.0.1:9000/",
      "health": { "url": "http://127.0.0.1:9000/api/health", "contains": "ok" },
      "cli": "mi-app",
      "repo": "yo/mi-app",
      "start":   { "unix": "mi-app serve",  "windows": "mi-app serve" },
      "install": { "unix": "curl -fsSL https://example.com/install.sh | sh", "windows": "irm https://example.com/install.ps1 | iex" },
      "update":  { "unix": "mi-app update", "windows": "mi-app update" },
      "mcp": { "command": "{cli}", "args": ["mcp"] }
    }
  ]
}
CampoPara qué sirve
kindweb (se abre dentro) o native (abre su propia ventana).
url, healthDónde está la app y cómo saber si está corriendo (la respuesta debe contener contains).
cliEl comando de la app; sirve para detectar si está instalada.
repoRepositorio de GitHub para ver versiones nuevas.
start, install, updateComandos por sistema (unix y windows).
mcpSu servidor MCP. Valores que se reemplazan: {cli} (ruta completa del comando), {home} (su carpeta), {uv} y {ws} (~/.workstudio).

El catálogo de la familia está en catalog/apps.json y sirve de ejemplo completo.

Adding apps

Any local app with a web interface, a command or an MCP server joins by adding it to the apps list in ~/.workstudio/apps.json. If it uses the same id as a catalog app, yours wins.

{
  "apps": [
    {
      "id": "my-app",
      "name": "My App",
      "tagline": "What it does",
      "kind": "web",
      "url": "http://127.0.0.1:9000/",
      "health": { "url": "http://127.0.0.1:9000/api/health", "contains": "ok" },
      "cli": "my-app",
      "repo": "me/my-app",
      "start":   { "unix": "my-app serve",  "windows": "my-app serve" },
      "install": { "unix": "curl -fsSL https://example.com/install.sh | sh", "windows": "irm https://example.com/install.ps1 | iex" },
      "update":  { "unix": "my-app update", "windows": "my-app update" },
      "mcp": { "command": "{cli}", "args": ["mcp"] }
    }
  ]
}
FieldWhat it's for
kindweb (opens inside) or native (opens its own window).
url, healthWhere the app lives and how to tell it's running (the response must contain contains).
cliThe app's command; used to detect whether it's installed.
repoGitHub repository used to check for new versions.
start, install, updateCommands per system (unix and windows).
mcpIts MCP server. Placeholders: {cli} (full path of the command), {home} (its folder), {uv} and {ws} (~/.workstudio).

The family catalog lives in catalog/apps.json and works as a full example.

Servidor MCP

workstudio mcp es un servidor MCP que arranca los servidores de tus apps, junta sus herramientas y reparte cada llamada. Las herramientas se llaman <app>__<herramienta>, por ejemplo brain__search_knowledge. Tus agentes ven un solo servidor en vez de una lista larga.

  • workstudio mcp --only brain,lumina,web lo limita a esas apps; web suma web__search y web__fetch de WorkStudio.
  • Los servidores MCP que agregues en la pestaña Servidores (stdio o http) viajan con él.
  • OpenCue expone las herramientas de un agente: elegilo en MCP → Servidores.

MCP server

workstudio mcp is an MCP server that starts your apps' servers, merges their tools and routes each call. Tools are named <app>__<tool>, for example brain__search_knowledge. Your agents see one server instead of a long list.

  • workstudio mcp --only brain,lumina,web limits it to those apps; web adds WorkStudio's web__search and web__fetch.
  • MCP servers you add in the Servers tab (stdio or http) travel with it.
  • OpenCue exposes one agent's tools: pick it in MCP → Servers.

Avisos

El centro de avisos (la campana) y Actividad juntan lo que pasa en tus apps: cambios en el vault de brain, reuniones de Lumina, apps que se inician o se detienen, clientes MCP conectados y versiones nuevas. Si lo activás en Ajustes, también llegan como avisos del sistema.

Notifications

The notification center (the bell) and Activity collect what happens in your apps: brain vault changes, Lumina meetings, apps that start or stop, connected MCP clients and new versions. If you turn it on in Settings, they also arrive as system notifications.

Actualizaciones

WorkStudio revisa GitHub y npm cada pocas horas (el intervalo se cambia en Ajustes) y te avisa. En Actualizaciones:

  • WorkStudio se actualiza solo con paquetes firmados; al terminar se reinicia.
  • Cada app se actualiza con su comando, en una terminal para que veas cada paso. Mientras corre, el botón dice «Actualizando…»; al terminar, WorkStudio vuelve a leer la versión instalada, cambia el número que muestra y saca el botón de actualizar.
  • Los CLIs de agentes (Claude Code, Codex, Gemini CLI, Cursor Agent) se actualizan igual.

Desde la terminal: workstudio update.

Updates

WorkStudio checks GitHub and npm every few hours (the interval is in Settings) and tells you. In Updates:

  • WorkStudio updates itself with signed bundles and restarts when done.
  • Each app updates with its own command, in a terminal so you see every step. While it runs the button says "Updating…"; when it ends, WorkStudio reads the installed version again, updates the number it shows and removes the update button.
  • Agent CLIs (Claude Code, Codex, Gemini CLI, Cursor Agent) update the same way.

From the terminal: workstudio update.

Problemas frecuentes

macOS dice que la app no se puede abrir

Los instaladores todavía no están firmados por Apple. El comando de instalación quita la marca de cuarentena. Si bajaste el .dmg a mano, hacé clic derecho → Abrir la primera vez, o corré xattr -dr com.apple.quarantine "/Applications/AI WorkStudio.app".

Una app figura como detenida pero está abierta

WorkStudio la da por corriendo cuando responde su dirección de salud (por ejemplo http://127.0.0.1:8765/api/version para brain). Revisá que use el puerto de siempre.

No aparece un modelo en el chat

Solo se listan los modelos cuyo CLI está instalado y en el PATH. Instalalo desde Terminales → CLIs y volvé a abrir el chat. Si un modelo de Codex devuelve error, puede que tu cuenta no lo tenga: elegí uno de los que figuran primero.

Un cliente MCP no ve las herramientas

Reinicialo después de conectarlo. Si sigue igual, desconectalo y conectalo de nuevo desde MCP → Clientes; la copia .bak-workstudio queda al lado del archivo original.

Dónde están los registros

En ~/.workstudio/logs. Si abrís un issue, sumá lo que diga ahí.

Troubleshooting

macOS says the app can't be opened

The installers aren't signed by Apple yet. The install command removes the quarantine flag. If you downloaded the .dmg yourself, right-click → Open the first time, or run xattr -dr com.apple.quarantine "/Applications/AI WorkStudio.app".

An app shows as stopped but it's open

WorkStudio considers it running when its health address answers (for example http://127.0.0.1:8765/api/version for brain). Check it uses its usual port.

A model doesn't show up in the chat

Only models whose CLI is installed and on the PATH are listed. Install it from Terminals → CLIs and reopen the chat. If a Codex model returns an error, your account may not have it: pick one of those listed first.

An MCP client doesn't see the tools

Restart it after connecting. If nothing changes, disconnect and connect it again from MCP → Clients; the .bak-workstudio copy sits next to the original file.

Where the logs are

In ~/.workstudio/logs. If you open an issue, include what's there.

Desinstalar

workstudio uninstall

En Windows también podés quitarla desde Configuración → Aplicaciones. Tus datos en ~/.workstudio quedan; borrá esa carpeta si no los querés. Si conectaste clientes MCP, desconectalos antes desde MCP → Clientes.

Uninstall

workstudio uninstall

On Windows you can also remove it from Settings → Apps. Your data in ~/.workstudio stays; delete that folder if you don't want it. If you connected MCP clients, disconnect them first from MCP → Clients.
